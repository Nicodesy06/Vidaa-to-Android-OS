# device/hisense/e7qpro — AOSP product stub

**Not a flashable image and not a complete device config.** It records the product
makefile shape a native/hybrid AOSP build for this board would take, and bundles the
OCL app. The hard blockers (signed bootloader, MediaTek TV HALs, DT/kernel) are
tracked in ../../../research/ and ../../../docs/blockers.md — this stub does not
pretend to solve them.
